GPS Tracking System - Time Range History

สิ่งที่แก้ไข:
- เพิ่มการเลือกวันที่ เวลาเริ่มต้น และเวลาสิ้นสุดในเมนู “ประวัติการเดินทาง”
- แผนที่จะแสดงเฉพาะพิกัดที่รถวิ่งในช่วงเวลาที่เลือก เช่น 11:00–12:00 น.
- เฟิร์มแวร์เพิ่ม localDate, localTime และ sortKey จากเวลา GNSS (แปลง UTC เป็นเวลาไทย UTC+7)
- ประวัติใหม่ใน Firebase จึงสามารถกรองตามวันและเวลาได้จริง
- ข้อมูลประวัติเก่าที่ไม่มีวัน/เวลาจริงจะไม่สามารถกรองตามช่วงเวลาได้
- ปรับสถานะ Offline: เมื่อไม่มีข้อมูลใหม่เกินกำหนด จะไม่แสดง “จอดอยู่”, ความเร็ว หรือจำนวนดาวเทียมจากข้อมูลเก่า
- คงรูปแบบ Dashboard, Marker, GPS และฟังก์ชันเดิมไว้

วิธีใช้งาน:
1. อัปโหลดไฟล์ GPS_Firebase_A7670E_GPS_TRACKING_TIME_RANGE.ino ลงบอร์ด LilyGO T-Call A7670E
2. รอให้บอร์ดบันทึกข้อมูล history ใหม่ใน Firebase
3. อัปโหลด index.html, manifest.webmanifest, service-worker.js และไฟล์ icon เดิมขึ้น GitHub repository ระดับ root
4. เปิดเมนู > ประวัติการเดินทาง > เลือกวันที่ > เวลาเริ่มต้น > เวลาสิ้นสุด > “แสดงเส้นทางตามช่วงเวลา”

หมายเหตุ:
- เวลาใน history ใช้เวลา GNSS แล้วแปลงเป็นเวลาไทย (UTC+7)
- History ยังบันทึกทุก 30 วินาทีตามค่า HISTORY_INTERVAL เดิม
